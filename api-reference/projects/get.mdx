---
title: Get Project
api: GET /v1/projects/{projectId}
---

Retrieves a single project by ID, including settings used for AI visibility tracking.

`tracking` says whether the project has data yet: `ready` is `true` once every active prompt has at least one AI answer. Poll it after creating a (pitch) project and adding prompts, before reading results or [creating a report](/api-reference/reports/create).

<ParamField path="projectId" type="string" required>
  MongoDB-style project identifier.
</ParamField>


<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.finseo.ai/v1/projects/67a1c2d3e4f5061728394a5b \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

```python Python
import requests

project_id = "67a1c2d3e4f5061728394a5b"
r = requests.get(
    f"https://api.finseo.ai/v1/projects/{project_id}",
    headers={"Authorization": "Bearer sk_live_xxxxxxxx"},
)
print(r.json()["data"])
```
