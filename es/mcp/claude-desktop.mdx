# Configurar Claude

Conecta Finseo con Claude para consultar tus datos de visibilidad en IA en lenguaje natural. El servidor MCP de Finseo admite OAuth: inicias sesión con tu cuenta normal de Finseo, sin necesidad de API key ni configuración JSON.

Funciona en **claude.ai (web)**, **Claude Desktop** y **Claude mobile**.

## Requisitos previos

- Una cuenta de Finseo con un plan de pago y al menos un proyecto de tracking
- Claude en un plan Free, Pro, Max, Team o Enterprise (los custom connectors están en beta)

## Configuración (claude.ai y Claude Desktop)

1. En Claude, ve a **Settings → Connectors**
2. Haz clic en **Add custom connector**
3. Introduce:
   - **Name**: `Finseo`
   - **Remote MCP Server URL**: `https://api.finseo.ai/v1/mcp`
   - Deja los campos de OAuth Client ID y Client Secret **vacíos** — Finseo admite Dynamic Client Registration, así que Claude se registra automáticamente
4. Haz clic en **Add** y luego en **Connect**
5. Se te redirige al inicio de sesión de Finseo. Inicia sesión y haz clic en **Allow access**
6. Listo: todos los tools de Finseo ya están disponibles en tus conversaciones

<Note>
En los planes Team y Enterprise, un Owner de la organización añade primero el connector en **Organization settings → Connectors**. Después, los miembros se conectan individualmente en **Customize → Connectors**.
</Note>

## Configuración (Claude Code)

Claude Code admite servidores MCP remotos con autenticación por header. Si prefieres una API key ([crea una aquí](https://app.finseo.ai/developer)):

```bash
claude mcp add --transport http finseo https://api.finseo.ai/v1/mcp \
  --header "Authorization: Bearer $FINSEO_API_KEY"
```

O conéctate sin key — Claude Code descubre el flujo OAuth automáticamente:

```bash
claude mcp add --transport http finseo https://api.finseo.ai/v1/mcp
```

## Uso

Una vez conectado, puedes hacerle a Claude preguntas como:

- "List my Finseo projects"
- "What's my visibility rate for project X in the last 30 days?"
- "Show me the top 10 competitors for my brand"
- "Which sources are most cited in my industry?"
- "How many prompts am I tracking and which ones perform best?"

Todos los tools de Finseo son read-only: Claude puede analizar tus datos pero nunca los modifica.

## Revocar el acceso

Desconecta el connector en la configuración de Claude cuando quieras. Esto invalida de inmediato los tokens emitidos. También puedes revocar el acceso desde el lado de Finseo contactando con el soporte.

## Troubleshooting

- **"Couldn't reach the MCP server"** — comprueba que introdujiste la URL exacta `https://api.finseo.ai/v1/mcp` (incluida la ruta).
- **Bucle de login o página de consentimiento que no carga** — asegúrate primero de poder iniciar sesión en [app.finseo.ai](https://app.finseo.ai) con el mismo navegador.
- **No se devuelve ningún proyecto** — tu cuenta necesita al menos un proyecto de tracking con datos.
