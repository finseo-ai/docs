# Configurar Cursor

Usa los datos de Finseo directamente en Cursor para analizar tu visibilidad en IA mientras programas.

## Requisitos previos

- Cursor IDE
- Una API key de Finseo con scope `read` ([consigue una aquí](https://app.finseo.ai/developer))

## Configuración

1. Abre los ajustes de Cursor
2. Navega a **MCP Servers**
3. Añade un nuevo servidor:

```json
{
  "finseo": {
    "url": "https://api.finseo.ai/v1/mcp",
    "headers": {
      "Authorization": "Bearer sk_live_YOUR_API_KEY"
    }
  }
}
```

## Uso

En el chat de IA de Cursor, puedes preguntar:

- "Use Finseo to check my brand visibility"
- "What are the top competitors in my Finseo project?"
- "Show my tracked prompts and their performance"
