# Integración MCP

Finseo ofrece un servidor Model Context Protocol (MCP) que permite a los asistentes de IA consultar tus datos de visibilidad directamente.

## ¿Qué es MCP?

MCP (Model Context Protocol) es un estándar para conectar modelos de IA con fuentes de datos externas. Con el servidor MCP de Finseo, puedes hacerle a Claude, ChatGPT o Cursor preguntas naturales sobre tu visibilidad en IA sin escribir código.

**Ejemplo**: Abre Claude y pregunta:

> "¿Cómo ha cambiado la visibilidad de mi marca en los últimos 30 días? ¿Qué competidores están por delante de mí?"

Claude consulta automáticamente tus datos de Finseo y ofrece el análisis.

## Guías de configuración

- [Claude (claude.ai, Desktop, Code)](/es/mcp/claude-desktop) — OAuth, no se necesita API key
- [ChatGPT (developer mode)](/es/mcp/chatgpt) — OAuth, no se necesita API key
- [Cursor](/es/mcp/cursor) — API key vía headers

## Autenticación

El servidor MCP admite dos métodos de autenticación:

| Método | Ideal para | Cómo |
|--------|----------|-----|
| **OAuth 2.1** | Claude, ChatGPT | Añade la URL del servidor e inicia sesión con tu cuenta de Finseo — el servidor admite Dynamic Client Registration y PKCE |
| **API key** | Cursor, clientes personalizados | Envía `Authorization: Bearer sk_live_...` ([crea una key](https://app.finseo.ai/developer)) |

## Tools disponibles

Todos los tools son **read-only**: obtienen datos y nunca los modifican.

| Tool | Descripción |
|------|-------------|
| `list_projects` | Lista todos tus proyectos con `language`, `isPitch` y `models` (los modelos de IA en los que se ejecutan los prompts del proyecto — los valores válidos para el filtro `model` de los demás tools) |
| `get_visibility_metrics` | KPIs de visibilidad — la tasa "Visibility" del dashboard (nombrada O citada), Mention Rate, Citation Rate y el recuento "Citations" del propio dominio, con comparación respecto al periodo anterior |
| `get_visibility_timeseries` | Visibilidad, mention rate, citation rate, mentions, posición ordinal (`avgMentionOrder`), profundidad de mención y sentiment por día (los mismos valores que el gráfico del dashboard) |
| `list_prompts` | Prompts trackeados con métricas (visible, mention rate, citation rate), principales competidores y citations por prompt (paginado mediante `offset`/`hasMore`) — devuelve el `id` del prompt usado por las herramientas de análisis detallado de prompts |
| `get_prompt_details` | Profundiza en un prompt: métricas por modelo e historial completo de respuestas (una fila por respuesta de IA con mención, profundidad, sentimiento y marcas nombradas) |
| `get_answer_content` | Lee las respuestas reales de la IA para un prompt en un día: texto completo, marcas con sentimiento y todas las fuentes citadas |
| `get_competitor_ranking` | Ranking de competidores con el conjunto completo de KPIs del dashboard: visibilidad (nombrada O citada), mention rate, citation rate, mentions, Share of Voice, posición ordinal (`avgMentionOrder`), profundidad de mención, #1/Top-3 share, head-to-head y citations — devuelve el `id` del competidor para las herramientas de análisis detallado |
| `get_competitor_gap_analysis` | Análisis de brechas frente a un competidor: respuestas donde solo aparece él (tus pérdidas), head-to-head y tus victorias — con los prompts concretos detrás |
| `get_competitor_h2h` | Comparación head-to-head con un competidor: quién se menciona primero, orden medio de mención y afirmaciones comparativas evaluadas por LLM |
| `get_sentiment_overview` | Sentimiento y Share of Voice: SoV sin límite con denominadores explícitos, ranking de sentimiento por marca con win rates y las afirmaciones más negativas evaluadas por LLM |
| `get_top_sources` | Fuentes más citadas con recuentos de citación y tipos de fuente |
| `get_tags` | Lista los tags con recuentos de prompts |
| `get_query_fanouts` | Query fan-outs de IA (sub-consultas) ordenados por frecuencia |
| `list_tasks` | Tasks de optimización generadas por IA (la página Tasks del dashboard), ordenadas por priority score, con filtros de estado/categoría/impacto — devuelve el `id` de la task usado por `get_task_details` |
| `get_task_details` | Una task completa: descripción, plan paso a paso, la evidencia que la originó y el content plan estructurado en tasks de contenido |

Los tools de analítica aceptan filtros opcionales de `model` (p. ej. `chatgpt`, `perplexity`, `ai_overview`, `gemini`, `grok`) y `tags` — los mismos filtros que el dashboard.

### Visibility, Mention Rate y Citation Rate

Una marca es **visible** en una respuesta de IA cuando se la nombra en el texto de la respuesta *o* se cita uno de sus dominios como fuente. Los tools reportan las tres tasas con el mismo denominador (todas las respuestas analizadas), así que se pueden comparar directamente (consulta [KPIs explicados](/es/getting-started/kpis)):

- `visibilityRatePercent` — nombrada **o** citada (el KPI "Visibility" del dashboard)
- `mentionRatePercent` — nombrada en el texto de la respuesta
- `citationRatePercent` — propio dominio (o un alias de dominio configurado) citado como fuente

Una misma respuesta puede contar tanto en Mention Rate como en Citation Rate, por lo que Visibility ≤ Mention Rate + Citation Rate. Ejemplo: *"Visibility 50 %, Mention Rate 45 %, Citation Rate 20 %"* significa que el 15 % de las respuestas nombran y citan la marca, el 30 % solo la nombran y el 5 % solo la enlazan.

### Definiciones de métricas

Los tools devuelven las mismas cifras que el dashboard de Finseo y las etiquetan de forma explícita:

- **`visibilityRatePercent`** — proporción de respuestas de IA analizadas en las que tu marca es visible: nombrada en el texto de la respuesta O tu propio dominio citado como fuente (el KPI "Visibility" del dashboard)
- **`mentionRatePercent`** — proporción de respuestas que nombran tu marca en el texto (el KPI "Mention Rate" del dashboard)
- **`citationRatePercent`** — proporción de respuestas que citan tu propio dominio o un alias de dominio como fuente (el KPI "Citation Rate" del dashboard)
- **`promptCoveragePercent`** — proporción de prompts trackeados con al menos una respuesta visible (un número distinto, normalmente mayor)
- **`brandMentions`** / **`ownDomainCitedAnswers`** — los recuentos absolutos detrás de Mention Rate y Citation Rate
- **`ownDomainCitations.total`** — respuestas de IA que citan tu propio dominio como fuente (el KPI "Citations" del dashboard)
- **`visibilityIsMentionOnly`** (ranking de competidores) — `true` cuando no se pudo resolver la parte de citaciones para esa marca y `visibilityRatePercent` equivale a la tasa basada solo en menciones

## Endpoint

```
POST https://api.finseo.ai/v1/mcp
```

El servidor implementa JSON-RPC 2.0 sobre Streamable HTTP y admite `initialize`, `tools/list` y `tools/call`. Las solicitudes no autenticadas reciben un `401` con metadatos de descubrimiento de OAuth según la especificación de autorización de MCP (RFC 9728).
