# Intégration MCP

Finseo fournit un serveur Model Context Protocol (MCP) qui permet aux assistants IA d'interroger directement tes données de visibilité.

## Qu'est-ce que MCP ?

MCP (Model Context Protocol) est un standard pour connecter les modèles IA à des sources de données externes. Avec le serveur MCP de Finseo, tu peux poser à Claude, ChatGPT ou Cursor des questions naturelles sur ta visibilité IA sans écrire de code.

**Exemple** : Ouvre Claude et demande :

> « Comment ma visibilité de marque a-t-elle évolué au cours des 30 derniers jours ? Quels concurrents sont devant moi ? »

Claude interroge automatiquement tes données Finseo et fournit une analyse.

## Authentification

Le serveur MCP prend en charge deux méthodes d'authentification :

| Méthode | Idéal pour | Comment |
|--------|----------|-----|
| **OAuth 2.1** | Claude, ChatGPT | Ajoute l'URL du serveur, connecte-toi avec ton compte Finseo — le serveur prend en charge le Dynamic Client Registration et PKCE |
| **Clé API** | Cursor, clients personnalisés | Envoie `Authorization: Bearer sk_live_...` ([créer une clé](https://app.finseo.ai/developer)) |

## Tools disponibles

Tous les tools sont en **read-only** — ils récupèrent des données et ne les modifient jamais.

| Tool | Description |
|------|-------------|
| `list_projects` | Lister tous tes projets avec `language`, `isPitch` et `models` (les modèles IA sur lesquels les prompts du projet s'exécutent — les valeurs valides pour le filtre `model` des autres tools) |
| `get_visibility_metrics` | KPIs de visibilité — le taux « Visibility » du dashboard (nommée OU citée), Mention Rate, Citation Rate et le décompte « Citations » du domaine propre, avec comparaison à la période précédente |
| `get_visibility_timeseries` | Visibilité, mention rate, citation rate, mentions, position ordinale (`avgMentionOrder`), profondeur de mention et sentiment par jour (mêmes valeurs que le graphique du dashboard) |
| `list_prompts` | Prompts suivis avec métriques (visible, mention rate, citation rate), top concurrents et citations par prompt (paginé via `offset`/`hasMore`) — renvoie l'`id` du prompt utilisé par les outils d'analyse détaillée des prompts |
| `get_prompt_details` | Explorez un prompt : métriques par modèle et historique complet des réponses (une ligne par réponse IA avec mention, profondeur, sentiment et marques citées) |
| `get_answer_content` | Lisez les réponses IA réelles d'un prompt pour un jour donné : texte complet, marques avec sentiment et toutes les sources citées |
| `get_competitor_ranking` | Ranking des concurrents avec l'ensemble des KPIs du dashboard : visibilité (nommée OU citée), mention rate, citation rate, mentions, Share of Voice, position ordinale (`avgMentionOrder`), profondeur de mention, part #1/Top-3, head-to-head et citations — renvoie l'`id` du concurrent pour les outils d'analyse détaillée |
| `get_competitor_gap_analysis` | Analyse des écarts face à un concurrent : réponses où lui seul apparaît (vos pertes), head-to-head et vos victoires — avec les prompts concrets derrière |
| `get_competitor_h2h` | Comparaison head-to-head avec un concurrent : qui est cité en premier, ordre moyen de mention et affirmations comparatives évaluées par LLM |
| `get_sentiment_overview` | Sentiment et Share of Voice : SoV non plafonné avec dénominateurs explicites, classement de sentiment par marque avec win rates et les affirmations les plus négatives évaluées par LLM |
| `get_top_sources` | Sources les plus citées avec nombre de citations et types de source |
| `get_tags` | Lister les tags avec le nombre de prompts |
| `get_query_fanouts` | Query fan-outs IA (sous-requêtes) classés par fréquence |
| `list_tasks` | Tasks d'optimisation générées par IA (la page Tasks du dashboard), triées par priority score, avec filtres statut/catégorie/impact — renvoie l'`id` de la task utilisé par `get_task_details` |
| `get_task_details` | Une task complète : description, plan étape par étape, les preuves à l'origine de la task et le content plan structuré pour les tasks de contenu |

Les tools analytics acceptent des filtres optionnels `model` (p. ex. `chatgpt`, `perplexity`, `ai_overview`, `gemini`, `grok`) et `tags` — les mêmes filtres que le dashboard.

### Visibility, Mention Rate et Citation Rate

Une marque est **visible** dans une réponse IA lorsqu'elle est nommée dans le texte de la réponse *ou* que l'un de ses domaines est cité comme source. Les tools rapportent les trois taux avec le même dénominateur (toutes les réponses analysées), ce qui permet de les comparer directement (voir [KPIs expliqués](/fr/getting-started/kpis)) :

- `visibilityRatePercent` — nommée **ou** citée (le KPI « Visibility » du dashboard)
- `mentionRatePercent` — nommée dans le texte de la réponse
- `citationRatePercent` — domaine propre (ou un alias de domaine configuré) cité comme source

Une même réponse peut compter à la fois dans le Mention Rate et le Citation Rate, donc Visibility ≤ Mention Rate + Citation Rate. Exemple : *« Visibility 50 %, Mention Rate 45 %, Citation Rate 20 % »* signifie que 15 % des réponses nomment et citent la marque, 30 % la nomment seulement et 5 % ne font que renvoyer vers son site.

### Définitions des métriques

Les tools renvoient les mêmes chiffres que le dashboard Finseo et les nomment explicitement :

- **`visibilityRatePercent`** — part des réponses IA analysées dans lesquelles ta marque est visible : nommée dans le texte de la réponse OU ton propre domaine cité comme source (le KPI « Visibility » du dashboard)
- **`mentionRatePercent`** — part des réponses qui nomment ta marque dans le texte (le KPI « Mention Rate » du dashboard)
- **`citationRatePercent`** — part des réponses qui citent ton propre domaine ou un alias de domaine comme source (le KPI « Citation Rate » du dashboard)
- **`promptCoveragePercent`** — part des prompts suivis avec au moins une réponse visible (un chiffre différent, généralement plus élevé)
- **`brandMentions`** / **`ownDomainCitedAnswers`** — les décomptes absolus derrière le Mention Rate et le Citation Rate
- **`ownDomainCitations.total`** — réponses IA citant ton propre domaine comme source (le KPI « Citations » du dashboard)
- **`visibilityIsMentionOnly`** (ranking des concurrents) — `true` lorsque le volet citations n'a pas pu être résolu pour cette marque et que `visibilityRatePercent` est égal au taux basé sur les mentions

## Endpoint

```
POST https://api.finseo.ai/v1/mcp
```

Le serveur implémente JSON-RPC 2.0 sur Streamable HTTP et prend en charge `initialize`, `tools/list` et `tools/call`. Les requêtes non authentifiées reçoivent une `401` avec des métadonnées de découverte OAuth conformes à la spec d'autorisation MCP (RFC 9728).
