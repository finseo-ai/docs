All tools on this page are **read-only**.

| Tool | Description |
|------|-------------|
| `list_tasks` | AI-generated optimization tasks (the dashboard Tasks page) sorted by priority score, with status/category/impact filters — returns the task `id` used by `get_task_details` |
| `get_task_details` | One task in full: description, step-by-step plan, the evidence that triggered it, and the structured content plan for content tasks |
